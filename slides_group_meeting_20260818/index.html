MOTIVATION

研究动机：Agent 授权的对象究竟是什么？

SRC §2·§4·§6
“启用一个扩展”时，系统各环节实际持有的是哪一层身份？
L1 · 名称 extension name 发现与选择向模型暴露的唯一信息（name + description）
L2 · 命令行 cmd + args 配置与授权的载体：npx -y pkg@latest
L3 · 版本 version OSV 信誉查询输入；latest 被源码显式归约为“无版本”
L4 · 制品 最终执行的 artifact 内容 只在 Goose 进程之外、activation 阶段由 npx 确定的字节 ?

研究问题 SRC §3

当授权与检查建立在 L1–L3，而实际执行的是 L4：在名称保持不变的前提下， 控制链路的任何一环能否察觉最终制品身份的变化？

本研究给出的初步回答 D1 §6 ｜ R1组 §2

在 Goose v1.45.0 的 stdio extension 激活路径上：不能。 admission 观测制品 A → activation 执行制品 B，全程无 artifact-specific 新授权。
